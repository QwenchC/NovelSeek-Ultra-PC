# ComfyUI 外网连接与证书授权

桌面 2.1.1 同步 Android 1.6.2 的 ComfyUI 自签名证书修复。没有自有域名时，可以使用穿透服务提供的域名和远程端口；证书必须匹配这个域名，并由你从电脑端公共证书独立核对完整 SHA-256 后授权。

## 填写服务地址

在“设置 → 图片生成引擎 → ComfyUI”填写服务基址。不要追加 `/system_stats`、`/prompt`、`/history` 或 `/view`；不要填写用户名、密码、查询参数、片段或登录页地址。

| 连接方式 | 地址示例 |
| --- | --- |
| 同一台电脑 | `http://localhost:8188` |
| 同一局域网 | `http://192.168.1.100:8188` |
| TCP 穿透 HTTP | `http://node.example.com:35961` |
| TCP 穿透自动 HTTPS | `https://node.example.com:35961` |
| 代理子路径 | `https://comfy.example.com/comfy` |

这些只是示例。裸 `主机:端口` 按 HTTP 处理，外网端口不会替换为本机 `8188`。启用自动 HTTPS 的隧道必须写明 `https://`；IP 地址通常不能代替证书中的域名。HTTP 地址可点击“切换 HTTPS 并核对隧道证书”，显式修改协议后再应用。

点击“应用图片设置”只保存图片引擎和地址，不修改文本模型。连接测试和证书操作使用当前输入；实际生成使用界面显示的已保存地址。未应用的草稿不会改变生成地址。

## 核对自签名证书

1. 在运行穿透客户端的电脑上确认实际使用的公共证书，独立取得完整 SHA-256 指纹。只检查 `.crt` 公共证书，不要上传私钥、隧道令牌或密码。
2. 填写完整 HTTPS 域名和远程端口，点击“应用图片设置”。
3. 点击“查看并核对服务器证书”，核对完整指纹、域名及有效期。网络弹窗本身不能独立证明服务器身份。
4. 一致后勾选“我已独立核对完整指纹，确认这是我的服务器。”，点击“仅授权此主机和端口”。默认未勾选，不能直接批准。
5. 测试连接，再生成一张小图确认模型和工作流正常。

不需要安装 Windows 系统证书或购买域名；APP 不改系统信任设置。已批准的完整指纹显示在设置页，可选中复制。证书重新生成或到期后必须重新从电脑端核对，不能因为连接失败就盲目批准陌生证书。[樱花 FRP 证书说明](https://doc.natfrp.com/frpc/ssl.html)

## 本机授权的范围

授权只保存在本机独立目录 `%LOCALAPPDATA%\com.novelseek.pro\comfy_tls_trust\certificates.json`，不进入 SQLite、可迁移设置或应用 ZIP／JSON 书库备份。导入手机或其他电脑的备份不会导入证书授权，每台设备需要单独核对。

授权绑定规范的 HTTPS 主机、有效端口和完整证书。同一来源下的代理路径可以共享授权；其他域名、端口及 HTTP 地址不继承。提交任务、查询进度、下载图片共用该授权，保留域名、有效期、证书用途及握手签名验证。其他文本模型、Embedding、Pollinations 的连接不改变。

点击“撤销本机授权”使旧授权版本失效，正在使用旧授权的请求和后续下载会停止。撤销保存失败时，当前进程仍拒绝使用旧授权，并提示重试；成功保存前不保证重启后仍处于撤销状态。

## 常见诊断

- 自动 HTTPS 提示或 HTTP 501：显式切换 HTTPS，核对证书，不跟随网页脚本。
- HTTPS／证书错误：检查主机名、时间、有效期和完整指纹；证书改变后先核对电脑端新证书。
- HTTP 200 但不是 ComfyUI API：可能是登录页或错误端口；测试要求真正的 `/system_stats` 数据。
- HTTP 3xx：APP 不跟随重定向，填写最终 API 基址，避免把提示词和请求交给其他地址。
- HTTP 401／403：网关拒绝或要求鉴权，目前不支持交互式登录或网关凭据，不要移除安全保护来绕过。
- HTTP 404 或网关错误：检查代理路径和隧道转发，全部生成路由都必须能访问。
- DNS、连接失败或超时：检查网络、域名、远程端口及隧道在线状态。

HTTPS 证书授权不是访问鉴权，不能防止其他人使用公开的无鉴权 ComfyUI。不要在公网 HTTP 传输敏感提示词或图片，优先使用受保护的网关或私人连接。

桌面原生客户端已通过真实公网 HTTPS 入口完成一次 256×256 图片的提交、轮询、下载和完整解码。验证范围和仍需人工验收的项目见 [2.1.1 验证记录](2.1.1-VERIFICATION.md)。
