# NovelSeek Ultra PC 2.1.0 更新说明

本次版本将 Android 1.6.0 的场景写作框架同步到桌面端，保留原有结构页、编辑器和经典智能体。数据通过设置页的 ZIP 或 JSON 备份双向交换，不依赖云账号。

## 写作工作台

- 项目默认进入工作台，仍可打开原结构与章节编辑页。
- 支持快速、场景、精修三种模式；本书风格、视角、禁用表达、示例文本和分工模型可独立配置。
- 作者维护设定、事实、角色认知与伏笔故事卡；事实来源正文变化后需要重新核对，避免把旧资料当作当前证据。
- 场景计划可以编辑；逐场景保存草稿、请求次数和恢复检查点。暂停、取消或来源变化时保留已完成草稿。
- 候选正文须经预览审核后采用，支持差异对照、部分采用与作者意见修订；采用前再次核对来源和当前正文，拒绝旧结果覆盖新编辑。
- 支持 TXT 与 Markdown 手稿预览导入，以及纯文本 EPUB 和 DOCX 导出。原 PDF 等导出保留。

## 智能体

经典执行链与规划执行引擎均可选，支持低、中、高推理级别。规划清单位于底部可收起区域，正文审核直接在会话内弹出预览。

会话显示供应商返回的缓存统计；没有统计的请求显示为未知，不视为零命中。上下文圆环是本地保守估算，预算接近上限时压缩历史摘要，原始记录仍保留。推理级别控制规划核对深度，不承诺所有模型都支持相同的原生推理参数。

新写作请求按请求身份独立取消，连续无数据或连接缺少完成标记时明确中断。JSON 规划与审稿使用结构化输出并验证字段，截断结果不会被当作完整动作或正文。

## 数据互通与恢复

请参阅 [两端数据交换说明](DATA_INTERCHANGE.md)。桌面保留自身的 2.x 版本序列，本次对应 Android 1.6.0。

ZIP 使用逐附件 SHA-256 校验；正文、插图、工作台偏好、故事卡、场景计划、检查点、用量和智能体会话可以交换。另一端的运行任务转为中断状态，外来会话不自动重放动作。跨端来源摘要不一致时，旧草稿可查看，但须按本端资料重新规划。

桌面导入将书库内容与元数据恢复日志一起提交到 SQLite，再持久保存元数据。中途退出后会先恢复未完成日志，恢复前禁止新任务。默认不导出 API 密钥，导入默认不覆盖本机模型与连接配置。

## 验证边界

自动测试使用模拟模型与测试数据库，104 项前端回归与 17 项原生测试通过，覆盖取消、恢复、严格 JSON、正文采用、备份损坏和持久化失败；两端实际 ZIP 编解码往返也已验证。具体结果与安装包记录见 [验证记录](2.1.0-VERIFICATION.md)。真实供应商 API、手机息屏、桌面长时间待机以及已有正式安装升级仍需人工验收。
