## 公网验证边界

先从本机穿透客户端实际使用的公共证书独立计算 SHA-256，确认没有私钥；公网观察证书必须与该完整指纹匹配。原生客户端使用证书中的域名与远程端口，不改为 IP，不改变 DNS、隧道、ComfyUI 或系统信任设置。

公网测试使用临时授权目录。连接／撤销检查执行一次，队列空闲后再显式执行一次带生成的检查，仅消耗一张小图，不写入任何小说。图片由生产 `ComfyUIClient` 的 `/prompt`、`/history/{id}` 和 `/view` 路径取得；没有只用 curl 或模拟响应替代生成验收。

联网测试不会在普通 `cargo test` 时运行。仅在获得服务器所有者授权、独立指纹和合适队列状态后启用：

```powershell
$env:COMFY_TEST_ORIGIN='https://node.example.com:35961'
$env:COMFY_VERIFIED_SHA256='<电脑公共证书独立核对的完整 SHA-256>'
$env:COMFY_GENERATE='1' # 可选；会消耗一次真实图片生成
$env:COMFY_TEST_PNG='<隔离测试图片输出绝对路径>' # 可选
cargo test --manifest-path src-tauri/Cargo.toml --bin novelseek-ultra-pc comfy_live_verified_origin_connection_and_optional_small_image -- --ignored --nocapture
```

证书授权在 `%LOCALAPPDATA%\com.novelseek.pro\comfy_tls_trust` 独立存储；可迁移 AppState、SQLite、设置及应用 ZIP／JSON 备份都没有增加授权字段。全部生成入口从原生本机状态获取授权快照，不接受智能体提供的证书授权。批准连接继续验证完整证书、域名、有效期、证书用途和握手签名，并禁用 TLS 会话恢复以避免新连接隐藏换证。撤销先使旧授权版本失效，再持久化；写入失败时本进程仍拒绝旧记录。
